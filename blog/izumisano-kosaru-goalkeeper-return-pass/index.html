バックパスの基本

相手に寄せられたら、後ろのキーパーへ戻したくなることも。フットサルには、その戻し方にも制限があります。初参加で迷いやすい場面を、短い具体例で整理します。

#泉佐野個サル#初心者#フットサルルール

泉佐野の個サルへ初めて参加するとき、「苦しくなったらキーパーに戻せばいい」と考える方もいるかもしれません。フットサルでは、キーパーが足で受ける場合にも制限があります。ここではJFAの競技規則をもとに、繰り返しパスを戻す場面と、手でボールを扱う場面を分けて説明します。当日の運用は、主催者の説明も確認してください。

01足で受けても、繰り返し戻せるとは限らない

JFAのフットサル競技規則2025/26では、キーパーがコントロールしていたボールをプレーしたあと、相手がプレーしたり触れたりしていないのに、味方が意図的に戻したボールへキーパーが自陣で再び触れると、相手の間接フリーキックになります。手で取らず、足で受ければいつでも大丈夫、というわけではありません。味方同士でパスを何本つないだかだけでも判断できません。

たとえば、キーパーからAさんへ出し、AさんからBさんへ渡したあと、相手が一度も触れていないままBさんがキーパーへ戻し、キーパーが自陣で足に当てる場面も、この制限の対象です。さらに別の決まりとして、味方が意図的にキーパーへ蹴ったボールは、自分のペナルティーエリア内でも手や腕で扱えません。これはキックインからのパスも含みます。

02泉佐野の個サルでは、開始前に戻し方を確認しよう

初参加では、バックパスをどのように扱うか、ゲームが始まる前に主催者へ聞いておきましょう。SERIE Wは初心者と経験者が一緒に楽しむ場で、球際を弱くするなどの安全ルールも案内しています。パス先に迷ったときにキーパーだけを探さず、横にいるフィールドの味方も見ておくと選択肢を持てます。参加を考えている方は、泉佐野の個サル開催日程を確認し、不安な点も公式LINEでお問い合わせください。
